개인정보처리방침

「그 회사 그 사람 업로더」 · 시행일 2026-11-25

1. 이 앱에 대하여

「그 회사 그 사람 업로더」(이하 "앱")는 유튜브 채널 「그 회사 그 사람」(https://www.youtube.com/@그회사그사람)의 운영자가 자기 채널에 직접 만든 영상을 올리고 관리하기 위해 쓰는 내부 도구입니다. 앱은 YouTube API 서비스를 사용합니다.

2. 사용하는 권한(범위)

  • https://www.googleapis.com/auth/youtube.upload: 운영자 채널에 영상 업로드
  • https://www.googleapis.com/auth/youtube: 운영자 채널의 영상 정보(제목·설명·태그·공개 예약) 수정, 썸네일 설정, 채널 정보 조회

3. 수집·이용하는 정보

앱은 운영자 본인의 Google 계정과 YouTube 채널에만 쓰입니다. 접근하는 정보는 업로드 결과(영상 ID, 공개 상태)와 운영자 채널의 기본 정보(채널 이름, 구독자 수, 영상 수 등)뿐이며, 운영자 채널을 관리하는 데만 씁니다. 다른 사용자나 다른 채널의 정보는 수집하지 않습니다.

4. 저장

Google이 발급한 인증 토큰은 운영자 컴퓨터에만 저장되며, 운영자만 읽을 수 있게 파일 권한을 제한합니다. 앱은 별도 서버를 두지 않고, YouTube에서 받은 데이터를 외부 데이터베이스에 저장하지 않습니다.

5. 제3자 제공·판매

앱이 Google API로 받은 정보는 제3자에게 제공·판매·공유하지 않으며, 광고에 쓰지 않습니다.

6. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API로 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

7. 관련 약관

앱은 YouTube API 서비스를 사용하므로, 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

8. 권한 철회

앱에 준 권한은 언제든지 Google 계정 보안 설정의 서드파티 액세스 페이지에서 철회할 수 있습니다. 철회하면 앱은 더 이상 채널에 접근할 수 없으며, 운영자 컴퓨터에 저장된 토큰도 삭제합니다.

Privacy Policy

Geu Hoesa Geu Saram Uploader (그 회사 그 사람 업로더) · Effective date: November 25, 2026

1. About this app

"그 회사 그 사람 업로더" (the "App") is an internal tool used by the operator of the YouTube channel "그 회사 그 사람" (https://www.youtube.com/@그회사그사람) to upload and manage videos they produce on their own channel. The App uses YouTube API Services.

2. Scopes used

  • https://www.googleapis.com/auth/youtube.upload: upload videos to the operator's channel
  • https://www.googleapis.com/auth/youtube: edit video metadata (title, description, tags, scheduled publishing) on the operator's channel, set thumbnails, and read channel information

3. Information accessed and how it is used

The App is used only with the operator's own Google account and YouTube channel. The only information it accesses is upload results (video ID, privacy status) and basic information about the operator's own channel (channel name, subscriber count, video count, etc.), used solely to manage that channel. The App does not collect any information about other users or other channels.

4. Storage

The authorization token issued by Google is stored only on the operator's computer, with file permissions restricted to the operator. The App has no server of its own and does not store data received from YouTube in any external database.

5. Sharing and sale

Information the App receives from Google APIs is not sold, shared with, or transferred to third parties, and is not used for advertising.

6. Google API Services User Data Policy

The App's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Related terms

Because the App uses YouTube API Services, the YouTube Terms of Service and the Google Privacy Policy apply.

8. Revoking access

You can revoke the App's access at any time from the Google Account security settings (third-party access). After revocation the App can no longer access the channel, and the token stored on the operator's computer is deleted.
